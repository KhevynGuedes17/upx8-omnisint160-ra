# Requisitos iniciais do MVP

Os requisitos abaixo representam a definição inicial do artefato e devem evoluir junto com a implementação.

## Requisitos funcionais

| ID | Requisito |
|---|---|
| RF01 | O sistema deverá permitir iniciar a experiência de Realidade Aumentada no dispositivo móvel. |
| RF02 | O sistema deverá reconhecer ou localizar a referência definida para o protótipo da OMNISINT 160. |
| RF03 | O sistema deverá apresentar a identificação de controles ou componentes selecionados. |
| RF04 | O sistema deverá apresentar a função e informação técnica associada ao controle/componente selecionado. |
| RF05 | O sistema deverá apresentar uma sequência operacional delimitada e previamente validada. |
| RF06 | O sistema deverá permitir navegar entre as etapas da sequência apresentada. |
| RF07 | O sistema deverá apresentar avisos contextuais quando o conteúdo possuir implicações de segurança. |

## Requisitos não funcionais

| ID | Categoria | Requisito |
|---|---|---|
| RNF01 | Usabilidade | A consulta deverá ser simples o suficiente para uso diante da máquina. |
| RNF02 | Segurança | A aplicação não deverá substituir treinamento, manual oficial, EPIs, sensores ou decisões do operador. |
| RNF03 | Desempenho | A aplicação deverá responder sem travamentos que impeçam a consulta. |
| RNF04 | Rastreamento | O rastreamento deverá ser estável no ambiente utilizado pelo protótipo. |
| RNF05 | Compatibilidade | Somente dispositivos efetivamente testados serão declarados compatíveis. |
| RNF06 | Conteúdo | O conteúdo técnico deverá ser derivado da documentação oficial e validado antes da avaliação. |
| RNF07 | Manutenibilidade | Código, assets e documentação deverão permanecer organizados e versionados. |

## Relação entre necessidade, funcionalidade e evidência futura

| Necessidade | Funcionalidade | Evidência prevista |
|---|---|---|
| Localizar um controle | Identificação contextual em RA | Acertos, erros e tempo |
| Recuperar uma etapa | Sequência operacional delimitada | Acertos, erros de ordem e tempo |
| Consultar função | Informação associada ao elemento físico | Sucesso da tarefa e observações |
| Avaliar experiência | Interface da aplicação | Medida de usabilidade e comentários, se prevista no protocolo |

> As evidências acima são planejadas. Não representam resultados já obtidos.
